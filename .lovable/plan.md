# ARTECHZO Professional Website Plan

## Goal
Build a complete, premium white-themed corporate website for ARTECHZO that presents the company as a credible software engineering, AI automation, and cloud deployment partner.

## Brand and visual direction
- Create two distinct original geometric ARTECHZO logo concepts combining an abstract A/Z with ideas of connectivity, software systems, and scalable infrastructure; refine the strongest concept for the site.
- Use a restrained white, ink, blue, and indigo palette with Geist-style precision, generous whitespace, subtle borders, and minimal shadows.
- Use custom technical diagrams and polished interface mockups instead of stock photography, generic icons, or fictional founder portraits.
- Add restrained entrance, scroll, line-flow, and interaction motion with reduced-motion support.

## Shared website structure
- Build a sticky, responsive header with active navigation, a functional mobile menu, and “Let’s Talk” action.
- Build a spacious global footer with real supplied company information only; omit unavailable phone, address, email, and social links.
- Centralize company, service, founder, technology, and product content so details stay consistent across pages.
- Add an accessible branded 404 page and intentional loading states where needed.

## Pages
1. **Home** — High-impact opening statement and connected technology visual, three core capabilities, three featured products, engineering principles, five-stage process, technology expertise, and closing contact prompt.
2. **Services** — Detailed sections for software engineering, AI automation, and cloud deployment, with capability lists, technical visuals, process, and contact actions.
3. **Products** — Premium overview of ICMT Conference 126, AR Tech Industries, and the AI Data Extraction Agentic Browser Engine using conceptual interface and workflow visuals.
4. **Product details** — A dedicated shareable page for each product with overview, problem, intended solution, functional areas, architecture illustration, responsible-use language where relevant, use cases, and contact action. No unsupported capability or production-status claims.
5. **About** — The authentic founder story, equal profiles for Ram Gibi and Aravind Rajan K using monogram portraits, company principles, and technology capabilities.
6. **Contact** — Professional inquiry form with name, business email, optional organization and budget, service selection, and project description.

## Cloud and hardware positioning
Use explicit language throughout relevant service content:

> ARTECHZO provides cloud architecture, deployment, configuration, automation, monitoring, and ongoing technical management. Cloud subscriptions, provider accounts, servers, and physical hardware are purchased and owned by the client. For private or on-premises deployments, ARTECHZO begins implementation after the client supplies suitable hardware and access.

This will be visible on the Services page and reflected concisely anywhere cloud delivery scope is described, preventing any implication that ARTECHZO sells or supplies hardware.

## Contact handling
- Build complete client-side validation, accessible errors, submission/loading states, and a clear configuration-dependent outcome.
- Since no contact delivery credentials or verified company email were supplied, do not claim that messages were delivered and do not invent contact details.
- Keep the form ready for later email or database integration, and clearly indicate when submission delivery is not yet configured.

## Search, accessibility, and quality
- Give every page unique titles, descriptions, Open Graph metadata, canonical URLs, and social card settings.
- Add sitemap and robots configuration plus verified-detail-only organization structured data.
- Use semantic headings, visible keyboard focus, accessible controls, WCAG-oriented contrast, and reduced-motion support.
- Verify navigation, mobile menu, product links, form behavior, content layout, overflow, and readability at small phone, tablet, laptop, and wide desktop sizes.
- Follow the project’s TanStack Start architecture while delivering the requested experience; no framework migration is needed.

## Technical details
- Implement reusable React/TypeScript components and data modules in the existing TanStack Start application.
- Use Tailwind CSS v4 semantic design tokens and existing design-system controls.
- Use generated raster artwork only where it materially improves the site; keep technical architecture graphics as responsive custom SVG/HTML compositions.
- Produce site-ready logo assets and a real favicon; generated PNG assets will not be represented as editable vector files.
- Add only lightweight dependencies when required and keep all links and actions functional.
